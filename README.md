# VLM_on_Edge
This repo serves as an exploration into deploying VLMs on edge compute devices ranging from 6 to 20+ TOPs, identifying model architectures and popular off-the-shelf models. The underlying objective is to investigate deploying VLMs for real-time object detection use.

The current roadmap is to perform a literature review and then develop tests and benchmarks for various vision tasks from detection to fault checking.

First attempt at attempting running VLMs on edge computing can be found on the work done for the SNIFF robot: https://github.com/sywise98/SNIFF.


This ongoing investigation will span across open-set object detection performance, fully onboard LLM-based conversation and reasoning, and more. SNIFF is an early look at the type of use-cases that onboard LLMs can enable on affordable and accessible IOT/edge compute hardware.
